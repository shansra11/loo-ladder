# Loo Ladder

A daily word ladder game with no ads. Start from a 4-letter word and change one letter at a time until you reach POOP. Every step has to be a real word, and par is the shortest possible ladder.

Play it at https://shansra11.github.io/loo-ladder/

- **Daily:** one shared puzzle per day, with streaks and stats saved on your device.
- **Unlimited:** endless practice puzzles that don't touch your stats.

The whole game is a single `index.html` file with no build step.
